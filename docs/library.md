# Library

The library lists every game Cairn knows about, whatever platform or launcher it comes from.

## Adding a game

Choose **Add game**, enter a name and pick a platform. Games added this way are labelled "Added manually". Editing a game changes its name and platform. Removing a game deletes only the entry in Cairn; game files on disk are never touched.

## Finding games

- **Search** matches every word you type against game names. Capitalization and accents are ignored.
- **Platform** shows one platform at a time.
- **Favorites only** shows games you have marked as favorites.
- **Sort by** orders games by name or by when they were added.

The library loads 48 games at a time. Choose **Show more** to continue. Pages are tied to the sort order, so adding games while you browse never repeats or skips entries.

## Where the data lives

Game entries are stored in Cairn's local database. See [Data management](data-management.md) for backups and restoring.

## Artwork

Each game can have a cover and a banner. Open a game, choose **Artwork**, then upload a PNG, JPEG or WebP image of up to 8 MB.

- **Cover** is portrait, 3:4, for example 600 × 800 pixels. It appears in the library, in the rows on Home and in the navigation rail for favorites.
- **Banner** is wide, 16:9, for example 1920 × 1080 pixels. It appears behind the game's title on its page and on Home when the game is featured.

Games without artwork show a tinted tile with their initials. Images are stored on this computer, next to the database, and are removed when you remove the game.

## Home

Home features a game and lists your favorites and the games you added most recently. The featured game is the first favorite or recent game that has a banner, or the first favorite if none has one.

## Collections

A collection is a named group of games that you manage yourself. Create one on the **Collections** page, then add games from a game's page. A game can belong to several collections.

- Collection names are unique, ignoring capitals and accents, and can be up to 60 characters.
- Choose a collection's name to see its games in the library. You can also filter the library by collection and combine that with search, platform and favorites.
- Collections that contain games appear as rows on Home.
- Deleting a collection, or removing a game from one, never removes the game. Removing a game from the library removes it from its collections.
