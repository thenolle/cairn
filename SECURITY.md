# Security Policy

Cairn runs a local service that can start programs and read game files, so security reports are taken seriously.

## Reporting a vulnerability

Do not disclose vulnerabilities through public issues, discussions or pull requests.

Use GitHub's private vulnerability reporting:

https://github.com/thenolle/cairn/security/advisories/new

Include:

- A description of the vulnerability.
- The affected components or versions.
- Steps to reproduce the issue.
- The potential impact.
- Any relevant proof of concept.

Do not include real credentials, personal information or private save data in reports.

## Supported versions

Security fixes are applied to the latest release. Older releases are not patched.
